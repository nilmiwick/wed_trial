# Wedding Invitation Website

## Files
- index.html — main invitation
- style.css — responsive design
- script.js — countdown
- images/ — add your wedding photos here

## Replace these placeholders
1. Names in `index.html`
2. Wedding date/time
3. Ceremony and reception venue/address
4. Google Maps links
5. RSVP Google Form link
6. `hero.jpg`, `couple.jpg`, `story.jpg`, `photo1.jpg` ... in the `images` folder

## RSVP
Create a Google Form and replace:
https://forms.google.com/
with your actual form URL in `index.html`.

## Publish for free
You can upload this folder to GitHub and enable GitHub Pages.
